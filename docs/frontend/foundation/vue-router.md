# Vue Router

## Что это

Официальный роутер для Vue.

## Когда брать

- Любые SPA/MPA с маршрутизацией.
- Нужны guards, nested routes, lazy loading.

## Основные возможности

- Декларативные маршруты.
- Ленивая загрузка страниц.
- Навигационные guard-ы.
