# Web реактивность

## Что это

Общий frontend-материал о видах реактивности в React, Vue и других UI-фреймворках.

## Когда смотреть

- Перед глубоким изучением Vue, React, Svelte, Solid и других UI-подходов.
- Когда нужно понять, почему современные фреймворки по-разному обновляют интерфейс.
- Для общего контекста перед сравнением state management, signals и fine-grained reactivity.

## Основные темы

- Эволюция реактивных подходов во frontend-разработке.
- Связь между состоянием приложения и обновлением DOM.
- Различия между coarse-grained и fine-grained обновлениями.
