# Nuxt (опционально)

## Что это

Meta-фреймворк над Vue для SSR/SSG.

## Когда брать

- Нужен SSR/SSG и готовая структура проекта.
- Нужны авто-роутинг, серверные эндпоинты, meta/SEO.

## Основные возможности

- SSR/SSG из коробки.
- Автоматическая маршрутизация.
- Серверные API (Nitro).

## С чем обычно вместе

- [Vue](/frontend/foundation/vue)
- [Vue Router](/frontend/foundation/vue-router)

## Альтернативы

- Vite + SSR вручную.
