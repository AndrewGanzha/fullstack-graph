# Vite

## Что это

Современный билд- и dev-сервер для фронтенда.

## Когда брать

- Новый Vue-проект с быстрым HMR.
- Нужна простая конфигурация и высокая скорость сборки.

## Основные возможности

- Мгновенный dev-сервер.
- Сборка через Rollup.
- Плагины для интеграции с Vue.
