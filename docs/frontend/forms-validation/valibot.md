# Valibot

## Что это

Лёгкая библиотека схем и валидации для TypeScript.

## Когда брать

- Нужен минимальный размер и скорость.
- Хочется схемную валидацию без «тяжёлого» API.

## Основные возможности

- Компактные валидаторы.
- Типизация и infer типов.
