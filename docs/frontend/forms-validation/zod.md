# Zod

## Что это

TypeScript-first библиотека для схем и валидации.

## Когда брать

- Нужна схема данных, которую можно переиспользовать.
- Нужны типы на основе схем.

## Основные возможности

- Инференс типов из схем.
- Валидация на клиенте и сервере.
