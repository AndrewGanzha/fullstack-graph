# VeeValidate

## Что это

Библиотека для валидации форм в Vue.

## Когда брать

- Нужны формы со схемной валидацией.
- Важна интеграция с UI-китом.

## Основные возможности

- Schema-based валидация.
- Компоненты и composables.

## С чем обычно вместе

- [Zod](/frontend/forms-validation/zod)
- [Valibot](/frontend/forms-validation/valibot)

## Альтернативы

- Самописная валидация, Vuelidate.
