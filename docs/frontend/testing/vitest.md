# Vitest

## Что это

Быстрый тест-раннер, совместимый с Vite.

## Когда брать

- Юнит- и интеграционные тесты в Vue-проектах.
- Нужна скорость и простая конфигурация.

## Основные возможности

- Совместимость с Jest API.
- Моки, снапшоты, coverage.
