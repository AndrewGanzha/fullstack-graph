# Playwright

## Что это

E2E тестирование браузерных сценариев.

## Когда брать

- Сквозные пользовательские сценарии.
- Нужен стабильный кроссбраузерный раннер.

## Основные возможности

- Тесты в Chromium/Firefox/WebKit.
- Трассировка и видео.

## С чем обычно вместе

- [MSW](/frontend/testing/msw)

## Альтернативы

- Cypress.
