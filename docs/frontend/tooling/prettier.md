# Prettier

## Что это

Форматтер кода с минимальной настройкой.

## Когда брать

- Нужен стабильный формат кода в команде.
- Хотите сократить споры о стилях.

## Основные возможности

- Автоформат при сохранении.
- Поддержка большинства фронтенд-форматов.
