# ESLint

## Что это

Линтер для JavaScript/TypeScript.

## Когда брать

- Нужен контроль качества кода.
- Нужно единообразие в командной разработке.

## Основные возможности

- Наборы правил и плагины.
- Автофикс форматирования части правил.
