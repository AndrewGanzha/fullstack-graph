# @tanstack/vue-query

## Что это

Управление асинхронными данными и кэшем для Vue.

## Когда брать

- Нужен кэш запросов, рефетч и инвалидация.
- Много серверных данных и сложных зависимостей.

## Основные возможности

- Кэширование и дедупликация.
- Фоновое обновление.
- Мутации и optimistic updates.

## С чем обычно вместе

- [Axios](/frontend/data/axios)
- [Pinia](/frontend/state/pinia)

## Альтернативы

- SWR-подход через composables.
