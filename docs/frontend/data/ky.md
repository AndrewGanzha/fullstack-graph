# Ky

## Что это

Минималистичный HTTP-клиент на базе fetch.

## Когда брать

- Нужен маленький и быстрый клиент.
- Не нужны сложные интерцепторы как в Axios.

## Основные возможности

- Удобный API поверх fetch.
- Ретраи и таймауты.

## С чем обычно вместе

- [@tanstack/vue-query](/frontend/data/tanstack-vue-query)

## Альтернативы

- [Axios](/frontend/data/axios), native fetch.
