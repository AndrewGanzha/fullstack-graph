# Pinia Colada

## Что это

Плагин для Pinia с акцентом на работу с server state, кэшем и асинхронными запросами.

## Когда брать

- Уже используете Pinia и хотите единый подход для клиентского и серверного состояния.
- Нужны кэширование, дедупликация запросов и управление статусами загрузки.

## Основные возможности

- Запросы и мутации с реактивным состоянием.
- Кэш и автоматическое обновление данных.
- Интеграция со store-моделью Pinia.
