# Типизированный Python

## Что это

Материал о практическом применении type hints и статической типизации в Python-коде.

## Когда читать

- При переходе от учебного Python к поддерживаемому backend-коду.
- Когда нужно лучше проектировать структуры данных, интерфейсы и границы модулей.
- Перед внедрением mypy, pyright или строгих правил ревью для Python-проекта.

## Основные темы

- Type hints и их влияние на читаемость и сопровождение кода.
- `NamedTuple`, `dataclass`, `TypedDict`, `Enum`, `Literal`, `Optional`.
- Дженерики, алиасы типов, протоколы и статические анализаторы.
